01 · Proyecto final DAW

Swimming Up

Aplicación web para la gestión integral de un club de natación: nadadores, grupos de entrenamiento, competiciones, calendario y registro de marcas. Incluye un panel de administración con autenticación y roles, una API JSON consumida por el frontend y un blog del club. Todo el entorno se levanta con Docker Compose, con Nginx como proxy inverso delante de cada servicio.
